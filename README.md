# Splitter

## Live Website

🔗 https://nikolozwdev.github.io/Splitter/

A simple and responsive web application built with HTML, CSS, and JavaScript.

Splitter focuses on creating a clean user experience with interactive elements, smooth UI behavior, and a lightweight structure without relying on external frameworks.

The project includes custom styling, dynamic content handling, and responsive layouts designed to work across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## About The Project

Splitter was created as a frontend project to practice building interactive web interfaces using core web technologies.

The main focus was on writing clean code, improving UI details, and creating a simple but polished user experience.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/NikolozWDev/Splitter.git
```

Open the project folder:

```bash
cd Splitter
```

Run the project by opening `index.html` in your browser.
